# Dependencies

- WolvenKit Console 9.1.0: downloaded from the official [release](https://github.com/WolvenKit/WolvenKit/releases/tag/9.1.0). GPL-3.0 license text is included here. Corresponding source: [tagged source archive](https://github.com/WolvenKit/WolvenKit/archive/refs/tags/9.1.0.zip). WolvenKit is a separate unmodified subprocess; its supplied native libraries and other dependencies remain in the tools folder. Consult that repository and dependency packages for their licenses before public redistribution.
- Microsoft .NET 8 self-contained Windows desktop runtime and .NET 10 x64 runtime for WolvenKit. The tool runtime's LICENSE.txt and ThirdPartyNotices.txt are included in `app/tools/runtime`. Upstream: [dotnet/runtime](https://github.com/dotnet/runtime), [dotnet/wpf](https://github.com/dotnet/wpf).
- No game archives or extracted original localization source trees are bundled with the application. The application reads the user's installed game. Generated mod output contains compiled resources derived from that installation.
- NcNc icon: generated with the built-in image generation tool, then encoded into a multi-resolution Windows ICO without changing the design. Source artwork is `source/Ncnc.App/Assets/NcNc.png`.

Huge bold angular condensed cyberpunk lettering, arranged as two lines Nc above Nc so it remains readable in a tiny taskbar icon. Electric yellow letters, subtle cyan offset glitch edges, nearly black graphite rounded-square badge, sharply chamfered futuristic corners, very simple high-contrast silhouette, minimal details, flat graphic logo styling. Letters occupy nearly all the badge with safe 8% outer margins. No additional text, no scenery, no mockup, no reflections, no gradients outside badge. Transparent background outside the badge. This is the final icon artwork, centered and isolated.”
